# PT-Plugin-Plus-MCP 使用帮助

`PT-Plugin-Plus-MCP` 是 PT-Plugin-Plus 的独立本机服务。它负责连接 OpenAI-compatible 模型服务和 MCP 工具；主扩展没有连接 MCP 时仍可正常搜索、下载和备份。

## 帮助页面

- [安装与启动](INSTALL.md)
- [配置模型与令牌](CONFIGURATION.md)
- [连接 PTPP](CONNECT.md)
- [安全与隐私](SECURITY.md)
- [常见问题](TROUBLESHOOTING.md)

请不要把 `.env`、API Key、bridge 令牌或真实站点数据提交到仓库，也不要在公开反馈中粘贴它们。
