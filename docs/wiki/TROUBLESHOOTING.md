# 常见问题

## PTPP 显示未连接

确认 MCP 服务正在运行，bridge 地址和端口一致，令牌没有多余空格。修改 `.env` 后必须重启服务，再在 PTPP 中点击“测试连接”。

## AI 请求超时

先确认模型服务地址和模型名称可用。模型响应较慢时，可以适当增加 MCP 服务端的可选超时；同时不要把 PTPP 的连接超时设置得过短。

## 关闭终端后服务停止

使用 `pnpm start:detached` 启动后台模式，或使用系统任务计划程序配置开机启动。关闭前台终端不会影响已独立启动的 bridge。

## AI 图标不出现

这是预期行为：只有 MCP 已启用且握手成功时才显示。普通 PTPP 功能不依赖 MCP，可以继续使用。

## 如何报告问题

请提供 MCP 版本、脱敏后的错误信息和复现步骤。不要上传 `.env`、日志中的密钥、站点地址、Cookie 或备份文件。
